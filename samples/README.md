# 课表样例文件（可直接用于"班级课表录入"）

这三个 `.xls` 是**教务系统那种"一格一课"的班级课表**，用 Excel 打开即可查看，
也可以直接拿到后台「数据录入 → 班级课表录入」里上传。

| 文件 | 班级名（由 A1 标题决定） | 班级人数 | 课程数 | 覆盖节次 |
| --- | --- | --- | --- | --- |
| `timetable_1_17jike.xls` | 17计科（2+3） | 42 | 12 | Mon1 Mon3 Mon7 Tue3 Tue5 Wed1 Wed3 Wed7 Thu1 Thu5 Fri1 Fri5 |
| `timetable_2_18ruangong.xls` | 18软工（1） | 38 | 10 | Mon1 Mon5 Tue1 Tue7 Wed1 Wed5 Thu3 Thu7 Fri3 Fri7 |
| `timetable_3_19wangong.xls` | 19网工（2） | 45 | 10 | Mon3 Mon5 Tue1 Tue3 Wed5 Wed7 Thu1 Thu3 Fri1 Fri7 |

三个文件合起来正好把周一到周五 × 4 个大节（共 20 个节次）全部铺满，
演示数据里的 9 名志愿者也是按这 20 个节次铺开的，所以按 README 的流程走一遍能排出完整的一张表。

## 表格布局要求（上传解析器认死这个格式）

```
        A            B          C        D        E        F        G
1  17计科（2+3）课表            ← A1 标题，解析时去掉"课表"两字作为班级名
2   节次          时间       周一      周二     周三     周四     周五
3  第1、2节   08:00-09:40   [课程]   [课程]  [课程]   [课程]  [课程]
4  第3、4节   10:00-11:40     ...
5  第5、6节   14:00-15:40     ...
6  第7、8节   16:00-17:40     ...
7~10 空行（解析按 行数-3 截断，行数太少会漏掉最后几个大节）
```

- 列 C~G 依次对应 `Mon`、`Tue`、`Web`(周三，原代码就是这么拼的)、`Thu`、`Fri`
- 行 3~6 依次对应 `Mon1`(第1、2节)、`Mon3`、`Mon5`、`Mon7`
- 一个格子里有多门课时，用换行分隔，每行一门

## 单元格文本格式

```
课程名/周次周/性质 教室/教师/人数/学分
```

例：

```
高等数学A/1-13周/理论 35-3jt/刘明/42/4.0
```

解析正则在 `ssm_web/src/main/resources/regular_expression.properties`，抓取 4 组：
课程名、周次（`1-13`）、教室（`35-3jt`）、教师（`刘明`），人数与学分丢弃。

> 周次请写成 `起始周-两位结束周`（`1-13`、`1-16`）。因为课表按周过滤的 SQL 用的是
> `left(course_time,2) <= 周 and right(course_time,2) >= 周`，结束周只有一位时会不准。

这些 `.xls` 由仓库外的一个小脚本用 `xlwt` 生成（BIFF8 格式，`jxl` 可读）。重新生成不影响使用，
如果你要改课程内容，直接在 Excel 里改完另存为 `.xls`（不要存成 `.xlsx`，`jxl` 读不了）。
